# Workshop Seed

Starting point for the AI-First SDLC workshop.

## What's here

- `docs/BRD.md` — Business Requirements Document. The product you'll build.
- `docs/backlog.md` — themes, one line each. Open-ended; Sprint N tackles theme N.

## Before we start

Read both files. Be ready to answer:

1. What's the product?
2. What are the roles in the system?
3. What's the first theme — and what would you build first if it were just you?

That's it. The rest we do together.
